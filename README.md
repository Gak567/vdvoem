# Вдвоём

Планировщик питания и воскресной готовки на двоих.

Статический сайт без сервера. Пользовательские нормы, планы, запасы и отметки покупок сохраняются только в localStorage браузера. Публичные профили содержат исключительно нейтральные демонстрационные значения.

Открыть: https://gak567.github.io/vdvoem/
